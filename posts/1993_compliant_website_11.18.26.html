Making a (Kind of) 1993 Compliant Website - 11.18.26

The Goal

The page should load on almost any device imaginable using only HTML tags that existed at the very beginning and only adding newer tags if I want them and they wont break the page.

The Tag Lists

1992 HTML

Nobody wrote HTML down properly at the start, so I picked the earliest official looking list I could find: the CERN tag list from November 1992. It origionally fit on a napkin.. Here is a list of what I plan to use

<title>
Name of the page and shows up in the tab or top browser bar.
<h1> to <h6>
Headings
<p>
A divider between two paragraphs.
<a>
Links
<ul> and <li>
Unordered and Bullet lists
<dl>, <dt>, <dd>
Glossaries. Like this one. Very meta.
Pro
Simple and elegant. Every browser should understands it.
Con
No bold, no italics, no images, and no quotes.

1993 HTML

There is no real "HTML 1.0." The closest thing is a draft from June 1993 by Tim Berners-Lee and Dan Connolly. Here is a list of what I plan to use:

<html>, <head>, and <body>
HEAD providing info about the page, BODY holding what the reader sees, and HTML wrapping the entire content.
<pre>
Text is presented EXACTLY like it is typed. Spaces, line breaks, characters and all. Great for ascii art.
Text styles: <b>, <i>, <u>
Basic bold, italics, and underline.

HTML 2.0 (1995)

I didn't end up wanting to use this, but figured it would be nice to link the first actual standard HTML 2.0 from November 1995.

CSS and Body Elements

I am a huge fan of the black background with white monospace text, but there wasnt any native way to do this before CSS or other body elements were added in ~1996. Browsers do however skip portions of an HTML file that have unqkown tags. So I made the decission to use body and CSS to make some style changes, while reverting to the origional white background with black text of 1993 web pages.
